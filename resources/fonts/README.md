# CV fonts

The fonts CVs can use, as Latin WOFF2 files. The web pages load them through Vite, and PDF exports attach the same files, so a CV looks the same on screen and on paper.

| Font | Licence |
|---|---|
| IBM Plex Sans | SIL Open Font License 1.1, `OFL-ibmplexsans.txt` |
| Instrument Sans | SIL Open Font License 1.1, `OFL-instrumentsans.txt` |
| Lora | SIL Open Font License 1.1, `OFL-lora.txt` |
| Source Serif 4 | SIL Open Font License 1.1, `OFL-sourceserif4.txt` |
